Proyecto Mercadito

Un proyecto de desarrollo web que simula la interfaz de un mercado o tienda en línea. Está diseñado para mostrar un catálogo de productos con una navegación sencilla y una estructura de páginas modular.

**[Ver el proyecto en vivo (GitHub Pages)](https://grattitomas.github.io/proyecto-mercadito-github/)**

Características principales
Catálogo de productos:Visualización de los artículos disponibles en la tienda.
Navegación estructurada:Diferentes secciones integradas a través de la carpeta `pages`.
Interfaz personalizada:Estilos y diseño visual propios.

Tecnologías utilizadas
HTML5: Para la estructura y semántica del sitio (`index.html` y vistas secundarias).
CSS3:Para el diseño, maquetado y estilos visuales (carpeta `styles`).
Recursos / JavaScript: Gestión de interactividad e imágenes (carpeta `assets`).

Estructura del repositorio
`/assets/` - Imágenes, iconos y scripts complementarios.
`/pages/` - Archivos HTML con las vistas secundarias del mercadito.
`/styles/` - Hojas de estilo para la personalización de la interfaz.
`index.html` - Página principal de la tienda.
